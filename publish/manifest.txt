# publish/manifest.txt, version 1
#
# The single source of truth for what does NOT travel into the public export.
# publish/publish.sh reads this file, and nothing else, to decide exclusions.
#
# Syntax, one rule per line:
#   path/          directory prefix, excludes the directory and everything under it
#   path/*.md      glob, matched against the repo relative path
#   path/file.md   exact repo relative path
#   !path          negation, keeps a path an earlier rule excluded
#   ?path/         expected zero, a defensive rule that is allowed to match no file
#   # comment      ignored, as are blank lines
#
# Every rule without the ? prefix must match at least one tracked file. A rule that
# matches nothing is treated as a typo and fails verification, since a typo silently
# protects nothing. Use ? only where matching nothing is the correct outcome, such as
# a path that is already gitignored and listed here as a second layer.
#
# Order matters only for negations: a negation wins over any rule above or below it.
#
# The export is built from `git ls-files`, so untracked and gitignored files never
# enter it by construction. Rules here are the second layer: tracked files that are
# real but private.

# ── This tooling ──────────────────────────────────────────────────────────────
# The export machinery ships. It is engine code, it carries no private content, and
# shipping it makes the public boundary self-documenting: a reader can see exactly
# what is held back and why. One file is the exception.
#
# publish/private-terms.txt is the scrub list that keeps private names out of the
# generated DECISIONS-INDEX.md. It is a list of exactly the words that are
# sensitive, so shipping it would hand a reader the map it exists to hide. The
# generator that reads it ships, and the index it produces ships: the mechanism is
# public, the vocabulary is not. No ? marker, because the file is tracked and this
# rule must match. A run where it matches nothing means the file was renamed or
# deleted, and the scrub is silently gone.
publish/private-terms.txt
