# Taste presets — pick exactly ONE per build

A preset is a committed *direction*, stated before code. It aims the `frontend-design`
skill away from the generic AI default. They are mutually exclusive — never stack them.

## minimalist
Editorial calm. Generous whitespace, one accent color, restrained type scale, no decorative
gradients. Content breathes. Reference feel: a well-set blog / Stripe docs. Best for: content,
writing, B2B clarity.

## premium
Luxury-brand landing. High contrast, large confident type, real imagery, refined serif or
grotesk pairing, deliberate negative space, subtle motion. Reference feel: a fashion/house brand.
Best for: hero/marketing where design *is* the product.

## brutalist
Anti-corporate, raw. Heavy weights, hard edges, visible structure, mono/system type, stark
palette. Best for: developer tools, statements, deliberately un-slick products.

## clean-default
Safe, professional, neutral. Solid product/company landing without anything extreme — clear
hierarchy, accessible contrast, no risk. Best for: client work that must look correct over
distinctive.

---
**Rule of thumb:** functional product UI → `clean-default` or `minimalist`; a landing/portfolio
where look sells → `premium` or `brutalist`. State which and why in one sentence before building.
